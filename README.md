## 📋 Présentation du Projet

Ce projet est une application web moderne construite avec **Next.js 15** (App Router) et une architecture **Headless CMS (WordPress)**. Il sert de vitrine officielle pour le Forum International de Libreville 2026, géré par le Commissariat Général aux Expositions du Gabon (CGEG).

### ✨ Fonctionnalités clés
* 🌍 **Multilingue (i18n)** : Support complet Français et Anglais via `next-intl`.
* 🖋️ **Gestion de contenu dynamique** : Intégration avancée avec WordPress & Advanced Custom Fields (ACF).
* 🎫 **Inscription en ligne** : Formulaire d'inscription complexe avec validation de données, gestion des civilités/titres et téléchargement de photos d'identité.
* 🛡️ **Validation & UX** : Validation robuste des formulaires côté client avec retours visuels via **SweetAlert2**.
* 🚀 **Rendu optimisé** : Utilisation du composant Image de Next.js et de la typographie Tailwind (`prose`) pour un rendu parfait du contenu venant du backoffice.

---

## 🛠️ Stack Technique

- **Frontend** : Next.js 15 (React 19), TypeScript, Tailwind CSS.
- **Backend (CMS)** : WordPress Headless via REST API.
- **UI Components** : 
    - `framer-motion` (animations)
    - `sweetalert2` (notifications/alertes)
    - `@tailwindcss/typography` (rendu du contenu HTML WordPress)
- **Internationalisation** : `next-intl`.
